=== Disk Sector and Size Calculations ===

--- Part C1: Slide Calculation ---
Given values:
  Sectors per track = 400
  Heads = 12
  Cylinders = 17,000
  Bytes per sector = 512

Step 1: Total sectors = 400 x 12 x 17,000 = 81,600,000 sectors
Step 2: Total bytes  = 81,600,000 x 512 = 41,779,200,000 bytes
Step 3: KB = 41,779,200,000 / 1,024 = 40,800,000.00 KB
Step 4: MB = 40,800,000 / 1,024 = 39,843.75 MB
Step 5: GB = 39,843.75 / 1,024 = 38.91 GB

OS-reported size (df -hT): 79G (ext4)
Difference explanation: The ~1 GiB difference between calculated (80.09 GiB)
and reported (79G) is due to ext4 file system overhead including:

  - Journal area
  - Inode tables and metadata structures
  - Block group descriptors
