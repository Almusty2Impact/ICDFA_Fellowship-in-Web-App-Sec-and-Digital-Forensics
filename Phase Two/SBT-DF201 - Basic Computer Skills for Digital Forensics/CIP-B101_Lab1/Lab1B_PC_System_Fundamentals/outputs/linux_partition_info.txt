=============================================================================
FORENSIC NOTES
=============================================================================

1. The NTFS volume serial number (A1B2C3D4E5F6A1B2) can be cross-referenced
   with Windows registry entries and event logs to confirm disk identity.

2. FAT32 EFI partition contains boot loader files that may reveal
   boot configuration changes and Secure Boot state.

3. Linux tools provide sector-precise partition boundaries essential for
   targeted imaging and file carving of unallocated regions.

4. The blkid PARTUUID values correspond to the GPT unique partition GUIDs
   and can be used to track partition reordering or tampering.
